## 1. Ringkasan Eksekutif

HelpDeskPro v1.1.0 menghadirkan modernisasi platform secara menyeluruh dengan melakukan migrasi solusi dari **.NET 8 LTS ke .NET 10 LTS**. Pembaruan ini mencakup peningkatan efisiensi runtime, pembaruan seluruh dependensi pustaka ke versi terbaru yang kompatibel, penegakan aturan penganalisis kode (*code analysis*) C# modern, penyesuaian arsitektur OpenAPI 2.0, serta migrasi komponen UI ke **MudBlazor v9**.

Seluruh 376 unit & integration tests tetap berstatus **100% Lulus (Green)** tanpa menonaktifkan satu pun pengujian atau menurunkan tingkat ketegasan kompilasi (`TreatWarningsAsErrors=true` dipertahankan secara ketat).

## 3. Rincian Breaking Changes & Solusi Kompilasi

### A. ASP.NET Core & MediatR 14
1. **Propagasi Pembatalan (`CA2016`) & Delegasi MediatR**:
   - `RequestHandlerDelegate<TResponse>` pada MediatR 14 mewajibkan penerusan `CancellationToken`.
   - Diperbarui pada `ValidationBehavior` dan `LoggingBehavior`: `await next(cancellationToken)`.
   - Diperbarui pada `LoggingBehaviorTests`: `RequestHandlerDelegate<string> next = (ct) => Task.FromResult("Success");`.

### B. OpenAPI.NET 2.0 & Swashbuckle 10
1. **Flattening Namespace `Microsoft.OpenApi`**:
   - Namespace `Microsoft.OpenApi.Models` telah dihapus/dilebur ke `Microsoft.OpenApi`.
   - Mengubah direktif import pada `Program.cs` API menjadi `using Microsoft.OpenApi;`.
2. **`OpenApiSecuritySchemeReference`**:
   - Penggunaan skema referensi keamanan beralih ke `OpenApiSecuritySchemeReference(string id, OpenApiDocument document)`.
   - Konfigurasi `AddSecurityRequirement` disesuaikan dengan callback dokumen: `options.AddSecurityRequirement(doc => new OpenApiSecurityRequirement { { new OpenApiSecuritySchemeReference("Bearer", doc), [] } });`.

### C. MudBlazor v9
1. **Abstraksi Dialog Instance**:
   - `MudDialogInstance` digantikan oleh antarmuka `IMudDialogInstance`.
   - Diperbarui pada seluruh 11 komponen dialog (`ConfirmDialog`, `CategoryFormDialog`, `DepartmentFormDialog`, `HolidayFormDialog`, `UserFormDialog`, `SlaPolicyFormDialog`, `ResetPasswordDialog`, `ChangeStatusDialog`, `AssignTicketDialog`, `EscalateDialog`, `RatingDialog`).
2. **Generik `ChartSeries<T>` & MudChart**:
   - `ChartSeries` kini berparameter tipe generic `ChartSeries<double>`.
   - Atribut usang `XAxisLabels` digantikan oleh `ChartLabels`.
   - Opsi `YAxisLines` dan `XAxisLines` disesuaikan dengan spesifikasi opsi grafik v9.
3. **Overhaul Tipografi MudTheme**:
   - Kelas tipografi konkret diperbarui (`DefaultTypography`, `H6Typography`, `Body1Typography`, `Body2Typography`, `CaptionTypography`, `ButtonTypography`).
   - Nilai properti tipografi (`LineHeight`, `FontWeight`) dimigrasikan ke tipe `string` standar CSS.
4. **Koleksi Multi-Select MudSelect**:
   - Tipe parameter `SelectedValues` pada `MudSelect<T>` multi-selection kini menggunakan `IReadOnlyCollection<T>`.

### D. Blazor Server Authentication Provider
- Menambahkan registrasi autentikasi skema default pada `Program.cs` Web UI (`builder.Services.AddAuthentication("Cookies").AddCookie(...)`) untuk memenuhi prasyarat autentikasi ASP.NET Core 10 middleware.
- Menyelesaikan ambiguitas parameter konteks `RZ9999` pada `MainLayout.razor` dengan mendeklarasikan `Context="authContext"` pada blok `<Authorized>`.

## 5. Panduan Menjalankan Solusi

### Prasyarat
- **.NET 10 SDK** (v10.0.404 atau lebih baru)
- **SQL Server 2022** (atau container MSSQL Docker)

### Perintah Build & Jalankan
```bash
# 1. Restore & Kompilasi Solusi
dotnet restore HelpDeskPro.sln
dotnet build HelpDeskPro.sln --no-restore

# 2. Jalankan Test Suite
dotnet test HelpDeskPro.sln --no-build

# 3. Jalankan API Server
dotnet run --project src/HelpDeskPro.Api --urls "http://localhost:5017"

# 4. Jalankan Blazor Web UI
dotnet run --project src/HelpDeskPro.Web --urls "http://localhost:5015"
```
